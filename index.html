Weather App

This project is a weather application built with Next.js and Material-UI. It allows users to search for weather information by entering a city name. The app fetches weather data using an API and displays it in two components.

The app uses React hooks (useState) for state management and Material-UI components for styling and layout.

Even though this is a very simple web application, it served as practice for using APIs and integrating them with web components.

EZ Sort (Alpha)

This project is a file sorter developed in python, by default, it takes a specific route and sorts all the files in folders by year, month and date. It's part of my personal project "EZFix", in which I focuse on giving a practical solution to common problems while trying to learn new technologies and techniques.

This project is going to support sorting customization, allowing the user to choose which files need to be sorted, as well as allowing to chose the categorization for the folders (Only by year, only year and month, etc...).

As a side note, I'm not using any AI for the development of any projects in EZFix to guarantee that I learn and understand the technologies and techniques used.
